## Customize Profile or Add New Projects
Edit [`src/data/portfolio.ts`](./src/data/portfolio.ts) to update your name, bio, email, skills, or add future projects.

## Local Development & Build
```bash
npm install
npm run dev
npm run build
```

## Deploy to Vercel
```bash
npx vercel --prod
```
*(Or push to GitHub and import the repo in Vercel — [`vercel.json`](./vercel.json) is already included.)*
